# 猎手 v7 筛选机制最优性审计：冠军交易员视角

> 2026-07-27 | 方法：错失机会量化（潜力池未命中标的前向收益回测）+ 多轮实时数据校验 + 冠军交易原则逐项对照
> 数据：过去 12 小时 10+ 轮实盘（6 轮盈利印证 + 多轮单点验证 + 3 轮审计轮），Binance USD-M 1m K 线前向判定

## 1. 审计方法：问市场要答案

筛选机制是否最优，不看它捕捉了什么，看它**漏掉了什么、漏掉的东西后来怎么走**。潜力池（validate 每轮记录的 top20 高潜标的及其模块命中状态）就是系统自带的盲区探测器。

**错失机会量化**（500 条池记录 → 154 条未命中 → 39 个去重高潜(≥50 分) → 24 个可取数标的 60 分钟前向回测）：

| 结论 | 数据 |
|---|---|
| 未命中高潜标的 71% 在 60 分钟内给出 TP0 级行情 | 17/24 MFE≥0.8%，MFE 中位 1.18% |
| **顶部错失集群几乎全是 SHORT** | SCR +8.8%、PRL +6.6%、EUL +4.9%、PIEVERSE +4.0%、LPT +3.0%（MAE 多数 ≤1.3%，风险干净） |
| 也有"漏得对"的 | DEXE SHORT MFE 0.6/MAE **-17.5**（接了会爆仓）、AGT LONG 0/-5.3——漏斗的保守性有真实价值 |

## 2. 诊断：结构性盲区在哪

**盲区一（已修）：强市中的相对弱势空单无人认领。**
trend_up 下空侧模块权重 0.4-0.6（运行但腰斩），更关键的是 SCR/PRL/EUL 这类"持续阴跌+卖流主导+无恐慌无拉升无梯次"的标的**不满足任何空模块的 Match**：distribution 要 24h+20% 拉升、panic 要恐慌烛、alt_ladder 要梯次结构、breakdown 要动量破位。冠军的经典猎物——"强势行情做空最弱者"（相对强弱是 O'Neil/Minervini 一系的核心，反向亦然）——正好落在空隙里。

**盲区二（已修）：相对强弱覆写不对称且不分方向。**
`strong_symbol_regime_override` 只救跑赢大盘的 LONG（RS>+6 且买流≥0.50 时权重回补 0.8）；跑输大盘的 SHORT 没有镜像通路。且旧实现不检查方向——SHORT 信号若坐在暴涨币上且买流强，也会被"加分"（语义倒挂）。

**判定为可接受的非盲区：**
- funding_reversal 在 trend_up 的 0 产出（逆势保护正确形态，前报已论证）；
- 单一全局 regime（BTC/ETH 基准）——相对强弱覆写已提供逐币级修正，升级为逐币 regime 属大改，现有数据不支持其必要性；
- 无时段感知（session awareness）——夜盘 EXEC 收窄由行情决定，数据未显示时段性系统偏差，不做过度工程。

## 4. 本次实施（全部 golden/测试门禁通过）

### 4.1 新模块 `relative_weakness_short`（填补盲区一）
- **Match（保守）**：4h≤-3% 且 24h≤-2% 且 1h∈(-5%, +0.5%]（阴跌不是坠落）、taker≤0.48（卖流主导，缺数据不入场）、排除 BTC/ETH。
- **打分**：弱势深度(30) + 跨帧持续性(20) + 统一卖流阶梯(20) + VWAP/EMA20 结构(20) + OI 确认(10)；空头拥挤费率打 `reduce_size_or_wait` 风险 tag（挤压意识）。
- **几何**：入场=弱反弹回区（zonePad 0.35%/0.5ATR）；失效=收复 1h 高点（收复即证伪阴跌论题）；目标=1h 低点回踩 + 1.5×ATR4h 延伸。
- **分级**：Ready 门 taker≤0.45（强卖流为确认腿）、Reviewable 门 ≤0.48——地板略高于 short/reversion 家族（该模块天然逆 regime，需更强证据）。
- **权重**：trend_up 0.9（这正是它的主场——强市猎最弱）、trend_down 1.2、panic 0.5（让位恐慌模块）。
- **词汇**：17 个新 reason/risk tag 全量登记目录（沿用 flow_ 卖流阶梯）。
- 架构验证：新形态 = 1 个模块文件 + 规则表 1 项 + 权重 6 行 + 目录登记——重构承诺的扩展成本兑现。

### 4.2 相对强弱覆写对称化 + 方向门（填补盲区二）
`strong_symbol_override` pass 重命名 `relative_strength_override`：LONG 凭相对强势+买流获得权重回补（原逻辑，加方向门）；SHORT 凭相对弱势（RS<-6）+卖流（taker≤0.50）获得镜像回补，打 `weak_symbol_regime_override` 证据码（已登记目录）。修复旧实现 SHORT 被强势币加分的语义倒挂。

### 4.3 验证记录
- 全量测试 + golden 双层逐字节（fixture 无受影响信号，改动纯前瞻性）。
- 新模块实盘验证轮：未开火——凌晨深跌标的行情已走完、当前未命中池分数仅 43-47（低于机会线），**保守不开火正是设计意图**；真实开火率与胜率由 `/hunter/v7/outcomes` 按 setup×regime 持续跟踪（新 setup 自动进入统计）。
- 附带发现：一轮出现 REST 部分覆盖告警（7.1% 瞬时网络错误，链路自愈，非机制问题）。
