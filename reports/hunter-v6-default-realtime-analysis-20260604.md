## 四、引擎设计意图——源码级解构

> 基于 `provider/local/hunter.go` (1583行) 源码逆向分析

### 4.1 四柱评分架构的权重真相

```
┌─────────────────────────────────────────────────────────────┐
│                    Composite Score 组装                       │
│                                                              │
│  base50 = max(Pos, OI) × 0.65 + min(Pos, OI) × 0.35       │
│           └───── 主导柱 A': 位置+OI 合体, 权重 65:35 ─────┘  │
│                                                              │
│  base25 = SmartMoney × 0.80                                 │
│           └── 聪明钱被打了8折 ──┘                             │
│                                                              │
│  composite = clamp(base50 + base25, 0, 75)                  │
│                                                              │
│  finalScore = composite × Cooldown × WashTrade + Squeeze     │
│               └── 再经三重惩罚 ──┘    └── 独立加分,免疫惩罚 ──┘│
│                                                              │
│  理论最大: ~100分  |  入场门槛: ≥15分  |  精英线: ≥20分       │
└─────────────────────────────────────────────────────────────┘
```

**关键洞察**: 代码中 `StrategyMode` 字段虽然有 `"default"` / `"breakout"` 两个值，但 **hunter.go 的评分函数完全不区分模式**——两种模式跑的是同一套四柱评分。模式差异体现在 **下游交易执行层**（trader/模块如何解读分数），而非筛选层本身。

这意味着：**default模式的筛选逻辑本质上不是"均值回归"，而是"结构位猎手"——它寻找的是价格到达关键结构位 + 资金面确认的共振点。**

### 4.5 Sniffer 机构伏击模式（后置过滤器）

在Hunter基础筛选之上，Sniffer额外施加5层门控：

| 门控 | LONG条件 | SHORT条件 |
|------|---------|----------|
| **Gate 1** 分数 | longScore ≥ 20.0 | shortScore ≥ 20.0 |
| **Gate 2** 压缩 | compressionScore ≥ 2 | compressionScore ≥ 2 |
| **Gate 3** 聪明钱 | oi_accumulation / taker_sustained_buying / lsr_reversal / oi_spike_1h / range_compression (任一) | oi_distribution / taker_sustained_selling / lsr_bearish_reversal / lsr_bearish_strong / oi_spike_1h / range_compression (任一) |

### 7.3 第三层：仓位管理公式

```python
# 基于引擎分数的仓位计算
def calc_position_size(score, tier, account_risk_pct=2.0):
    """score: 引擎综合分, tier: A/B/C/D层, account_risk_pct: 单笔最大亏损%"""

    # 信号置信度系数
    confidence = {
        'A': min(score / 60.0, 1.0),   # 60分 = 满置信
        'B': min(score / 40.0, 0.7),   # 40分 = 满置信, 封顶70%
        'C': min(score / 30.0, 0.4),   # 30分 = 满置信, 封顶40%
        'D': 0                          # D层不操作
    }[tier]

    # 止损距离 (ATR倍数)
    sl_atr = {  # 根据引擎ELP设定
        'A': 2.0,   # 2×ATR止损
        'B': 1.5,   # 更紧止损
        'C': 1.0,   # 极紧止损
    }[tier]

    # 仓位 = 账户风险 / (止损距离 × 信号置信度)
    position_pct = (account_risk_pct / sl_atr) * confidence

    return min(position_pct, 5.0)  # 硬封顶5%

# 当前标的仓位建议:
# HOME (C层, 14.4分): position = 2% / 1.0 × min(14.4/30, 0.4) = 0.8%
# → 极小仓位试探, 等信号升级再加仓
```
